# 表情包

这里放的是**图**，按画面上的词来认（比心、无语、睡觉）。不是她的情绪分数，也不是人设。

自带 `plain/` 是六张占位小图，方便工具能跑。大肥鱼那套贴纸的许可是 personal，不随仓库分发；
想用就自己放进数据目录 `meme-packs/dafeiyu-001/`（默认配置先找它，找不到自动用占位）。

## 自己加一套

在数据目录（默认 `~/.dsh-fish-river/meme-packs/<包名>/`）放：

```
pack.json
某张图.png
```

`pack.json`：

```json
{
  "id": "mine",
  "name": "我的",
  "items": [
    { "file": "某张图.png", "tags": ["睡觉", "躺平"] }
  ]
}
```

- `file` 必须是这个目录里的相对路径，不能写 `..`。
- `tags` 描述画面里有什么。
- 图片只认 png / jpg / webp / gif，单张大小跟设置里的相册上限走。
- 设置页「表情包」里把包名填进「启用的包」，并打开开关。同名时，数据目录里的那套盖过自带的。

她用 `pick_meme` 按词挑一张，拿到路径。想发出去再自己调 `send_image`。不会每轮自动发。
